# 配置快捷指令

快捷指令是保存为 Markdown 文件的提示词：写好一次，以后输入 `/` 和名称即可复用。选中后，提示词会填入输入栏，修改后再发送。快捷指令还可以接收参数、为本会话切换智能体或模型，并在发送时填入 shell 命令的输出。

## 快捷指令文件放在哪里

| 目录 | macOS 和 Linux | Windows | 是否加载 |
| --- | --- | --- | --- |
| 你自己的快捷指令 | `~/.chrys/shortcuts` | `%APPDATA%\chrys\shortcuts` | 默认加载 |
| 项目的快捷指令 | 工作目录及其上级目录（直到仓库根目录）中的 `.chrys/shortcuts` | 同左 | 默认加载 |
| 另外添加的目录 | 任意目录，例如团队共享的目录 | 同左 | 添加后加载 |

读取哪些目录可在“设置 → 快捷指令”（`/settings shortcuts`）中选择，详见[快捷指令设置](../configuration/settings.md#快捷指令)。修改后，下次输入 `/` 时生效。

项目的 `.chrys/shortcuts` 必须位于仓库内：如果它是指向仓库外目录的链接，iCode 会跳过它。要使用团队共享的目录，请在“设置 → 快捷指令”中添加。

文件名就是快捷指令的名称：`review.md` 对应 `/review`。子目录中的文件名称带上目录：`git/commit-msg.md` 对应 `/git/commit-msg`。不同目录中有同名快捷指令时，使用最先读到的那个，顺序为：你自己的快捷指令、另外添加的目录、最近的项目目录。

要查看已加载哪些快捷指令及其来源目录，输入 `/runtime` 并打开“快捷指令”标签页。

## 编写快捷指令

快捷指令文件是 Markdown 文件，开头可以在两行 `---` 之间写设置：

```text
---
description: 审查我未提交的改动
agent: QA
model: my-provider/my-model
---

审查以下改动，先指出缺陷：

!`git diff --stat`

重点关注 $ARGUMENTS。
```

| 设置 | 作用 |
| --- | --- |
| `description` | 在 `/` 列表中显示在名称后面。 |
| `agent` | 发送时切换到的智能体。 |
| `model` | 发送时切换到的模型：模型配置的名称，或 `provider/model`。 |

设置之后的全部内容就是提示词。文件格式与 opencode 的命令相同，从 `.opencode/commands` 复制到快捷指令目录的文件可以直接使用。

提示词中可以使用：

- `$ARGUMENTS`：名称后输入的全部内容。
- `$1`、`$2`…：按空格拆分的单个参数；含空格的参数用引号括起来（`"会议改到下午"`）。编号最大的那个会接收剩余的全部参数。
- `` !`命令` ``：发送时在工作目录中运行该命令，并用它的输出替换这一处。

## 使用快捷指令

1. 在输入栏输入 `/`，快捷指令列在“快捷指令”分组中。
2. 选中一个，或输入名称和参数（`/review 错误处理`）后按 **Tab** 或 **Enter**。
3. 提示词会填入输入栏。没有给出的参数会高亮显示：按 **Tab** 在它们之间跳转，直接输入即可填写。仍有空位时按 **Enter**，iCode 会先提醒一次再发送。
4. 按需修改提示词，然后按 **Enter** 发送。

### 提示词中的命令

发送时，输入栏中的每个 `` !`命令` `` 会先运行，并用其输出替换。每条命令最多运行 10 秒，输出最多保留 16 KB。命令运行期间可按 **Esc** 取消。命令无法启动、超时或被取消时，提示词不会发送，仍保留在输入栏中。

只要发送时会运行命令，输入栏上方的卡片就会显示条数，例如 `发送时运行输入栏中的 2 条命令`。

选中快捷指令后，在你清空或替换输入栏内容之前，无论怎样编辑，它都算这个快捷指令的提示词。按 **Enter** 时输入栏中能看到的每个 `` !`…` `` 都会运行，包括你自己输入或粘贴的。不经过快捷指令、自己输入的消息不会运行命令。

### 智能体和模型

快捷指令设置的 `agent` 或 `model` 与当前不同时，输入栏上方会显示一张卡片，列出变化，例如 `Code → QA`。发送后，本会话会切换过去，并在本会话中一直沿用。新建会话（`/new` 或 `/clear`）会回到之前使用的智能体和模型，默认模型也不会改变。

如果不想切换，点击卡片上的“✕ 不切换”后再发送。自己用 `#` 选择智能体或用 `$` 选择模型，也会取代卡片的切换。文件中写的智能体或模型找不到时，卡片会提示，发送时沿用当前的设置。
